# 작가 원고의 사전 분기 준비 기준

## 결정

작가는 본인의 원작 본문과 원작 결말을 쓴다. 시스템은 확정된 원고의 **각 파트 끝**을 읽고 선택지 2개를 AI로 미리 제안한다. 독자에게는 원작 경로 1개와 제안된 대체 경로 2개, 총 3개가 즉시 보여야 한다. 선택지를 보여주기 위해 독자를 AI 생성 대기 상태에 두지 않는다. 선택 후 아직 저장된 결과가 없는 경로의 다음 이야기만 생성하고, 검수된 동일 결과는 재사용한다.

현재 작가 스튜디오는 전체 원고를 한 번에 저장하며 파트별 완료 이벤트가 없다. 이 버전에서는 **원고 버전 저장 성공과 파트 경계 검증 완료**를 그 원고에 포함된 각 파트의 완료 시점으로 본다. 추후 파트별 저장 기능을 만들더라도 같은 준비 작업을 파트 단위로 호출한다.

## 처리 순서

1. 작가가 원고를 붙여넣고 파트 제목과 경계를 확인해 제출한다. 원문은 불변 원고 버전으로 보존한다.
2. 서버가 원고 버전, 파트 키, 해당 파트 본문 해시, 언어, 프롬프트 버전을 묶어 파트별 비공개 준비 작업을 등록한다. 같은 입력의 재시도는 추가 AI 호출을 만들지 않는다.
3. 작업자는 해당 파트의 본문과 승인된 설정·관련 앞부분 맥락을 읽고, 원작 이후에 **실제로 다른 사건으로 이어질** 대체 선택지 2개를 생성한다. 작가의 원문이나 원작 결말을 수정하지 않는다.
4. 1번은 작가의 다음 파트 또는 원작 결말에 연결한다. 2·3번은 서로 다른 `generation_required` 경로로 저장한다. 문구 중복, 원작과 같은 즉시 합류, 설정·시간 충돌, 금지 콘텐츠, 비용 상한 초과는 실패로 남긴다.
5. 작가는 제안된 선택지를 확인·수정·승인한다. 승인된 문구와 원고 버전을 함께 고정해 공개용 소스 맵에 넣는다. 수정된 원고 버전에는 이전 승인을 재사용하지 않는다.
6. 공개 전 서버는 모든 공개 파트의 마지막 장면에 1·2·3이 저장됐고 해당 원고 버전의 승인과 일치하는지 확인한다. 하나라도 빠지면 선택형 공개를 거부한다.
7. 독자가 파트 마지막에 도착하면 저장된 선택지 3개를 즉시 받는다. 1번은 작가의 원문 경로이고, 2·3번은 선택 시 새 전개를 생성하거나 이미 검수된 결과를 재사용한다.

## 실패와 운영

- AI 제공자가 실패하거나 작업 결과가 불확실하면 자동 재결제·무한 재시도를 하지 않는다. 그 파트는 `준비 실패`로 남기고 작가/운영자에게 조치가 필요하다고 표시한다.
- 원고는 공개됐지만 분기가 없으면 `원고 공개 / AI 분기 미활성`으로 구분한다. 이를 선택형 작품 완성으로 집계하지 않는다.
- AI 사용 권한, 문체 참고, 결과 재사용, 이미지 변환 권한은 별도로 기록한다. 관리자가 작가의 동의를 추정해 대신 승인하지 않는다.
- 선택지 제안 비용은 작가 원고 준비 비용이다. 독자의 분기 생성 비용이나 독자별 AI 할당량에 청구하지 않는다.

## 완료 검수

- 서로 다른 두 작품에서 초반·중간·마지막 파트를 골라 1·2·3 표시와 선택 이후 서로 다른 사건 전개를 확인한다.
- PC와 모바일 390px·400px에서 마지막 페이지 선택지가 잘리지 않고, 앞 페이지의 `다음 장면`과 분기 선택이 구분되는지 확인한다.
- 한국어 원문을 기준으로 기존 5개 언어의 선택지 번역 상태를 표시한다. 번역이 없으면 다른 언어에서 임의의 번역을 만들어 공개하지 않는다.
- 기존 두 작품은 AI 권한 승인, 저장된 선택지 완전성, 실제 독자 화면의 1·2·3 확인이 끝나기 전까지 완료로 보고하지 않는다.
