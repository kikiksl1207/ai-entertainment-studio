# 루미나 선택극장: 인물·장면 연속성 제작 기준

이 문서는 실제 영상 생성 기능의 구현 기준이다. 현재 공개 화면의 업로드·분기 재생 기능과는 별개이며, 이 문서만으로 자동 생성이 구현된 것은 아니다.

## 확인된 제작 문제

- 어린이와 성인이 한 샷에 있으면 체형·키·나이가 서로 섞일 수 있다.
- 프롬프트만 반복하는 것보다 승인된 스틸컷 여러 장을 먼저 만든 뒤 영상화할 때 인물이 덜 흔들렸다.
- 아동 위험·잔인한 행동을 직접 묘사하는 샷은 생성 서비스의 안전 심사에서 거절될 수 있다.
- 2~4초 단위의 샷을 편집해 연결했을 때 긴 영상 한 번 생성보다 검수와 교체가 쉬웠다.
- 이번 수동 테스트의 총 지출은 승인된 결과 약 40초에 약 3만 원이었다. 모델 단가가 아니라 재시도까지 포함한 **승인 1초당 실제 비용**을 기록해야 한다.

## 장면 준비

1. 작품의 인물별 기준 묶음: 정면·45도·측면·전신·의상·표정·상대 인물과의 키 차이를 승인된 이미지로 저장한다. 어린이와 성인은 각각 분리된 참조 묶음과 명확한 신장·연령대 정보를 갖는다.
2. 배경 기준 묶음: 장소, 시간대, 조명, 주요 소품, 카메라 방향을 고정한다. 인물·배경·화풍은 별도의 참조 자산으로 관리한다.
3. 샷별 첫 프레임을 먼저 제작·승인한다. 모델이 지원하는 경우 마지막 프레임도 승인한다. 두 인물이 동시에 등장하는 경우 합성된 구도 스틸을 먼저 검수하고, 체형 혼동이 심하면 리액션 샷을 분리한다.
4. 영상 생성은 기본 2~4초로 시작하고, 동작이 복잡한 샷만 별도 비교한다. 기본 출력은 16:9 가로형으로 맞춘다. 참조 이미지가 있다고 동일 인물이 보장되는 것은 아니므로 얼굴·체형·의상·배경을 각 샷에서 검수한다.
5. 공통 영상의 마지막 승인 프레임을 모든 분기의 출발점으로 재사용한다. 분기 뒤의 이야기와 샷은 각 선택의 상태를 따라 별도로 제작하며 억지로 합류시키지 않는다.

## 모델 비교와 비용

- 같은 2~4초 샷, 같은 참조 이미지, 같은 출력 해상도로 최소 두 모델을 비교한다. Runway Dev에서 모델별 이미지 참조·첫/마지막 프레임 지원 범위는 다르므로 호출 전에 해당 모델 입력 제한을 확인한다.
- 최초 비교는 720p에서 진행한다. 1080p 확대는 **승인 샷만** 한다. `gen4_turbo`와 `wan3` 같은 저비용 후보를 먼저 비교하되, 선택 기준은 단순 초당 요금이 아니라 승인율과 재생성 비용이다.
- 각 요청에 작품·분기·샷 ID, 모델·설정·프롬프트 버전, 참조 이미지 해시, 생성 길이, 크레딧, 실패 코드, 승인 여부를 기록한다. `승인된 총 길이 / 생성된 총 길이`와 `총 지출 / 승인된 총 길이`를 보고한다.
- 동일한 승인 샷은 해시와 콘텐츠 버전으로 저장해 모든 이용자에게 재사용한다. 새 선택 경로의 최초 제작비와 반복 재생 비용은 별도로 계산한다.

## 안전 심사와 QA

- 아동이 등장하는 위험 장면과 폭력 묘사는 생성 전 스토리보드 단계에서 검토한다. 허용되지 않는 장면은 서비스 정책에 맞는 연출로 수정한다. 필터를 피하기 위한 문구 변형이나 실패 요청 자동 반복은 하지 않는다.
- Runway의 `SAFETY.*` 실패는 입력/출력 안전 심사 결과로 취급해 즉시 중단하고 담당자 검토로 보낸다. 안전 실패는 크레딧 환불 대상이 아니므로 비용 장부에 남긴다.
- 자동 검사는 얼굴·체형·의상·소품·색감·첫/마지막 프레임의 급변을 경고하는 보조 수단이다. 최종 승인은 사람이 실제 이어 붙인 화면과 소리를 보고 한다.
- 공개 전 PC·모바일 가로 전체화면에서 분기 선택 시점, 선택지 가독성, 이어지는 영상의 첫 프레임, 자막·음성, 재생 실패 후 복구를 테스트한다.
