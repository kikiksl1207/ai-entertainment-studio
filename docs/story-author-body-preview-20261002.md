# 2026-10-02 작가 전용 현재 루트 본문 확인

## 1. 목적

공개 독자 화면에서 분기 그림 준비가 실패하면 본문까지 보류되는 문제가 있다.
공개 제공 조건은 유지하면서, 소유 작가는 자신의 기존 독자 경로에 저장된 본문을
비공개로 확인할 수 있도록 읽기 전용 화면과 조회 API를 추가했다.

이 기능은 본문을 새로 만들거나 다음 선택을 실행하는 기능이 아니다. 그림 준비,
새 유료 본문 생성, 작가 검수 승인, 검수된 공유 재사용, 엔딩 완주는 별도 미완료다.

| 범위 | 현재 상태 |
| --- | --- |
| 소유 작가의 현재 경로 본문 조회 | 구현 및 로컬 검증 완료 |
| 원작/생성 장면, 선택지 표시, 종료 상태 | 구현 및 로컬 검증 완료. 선택지는 조회만 가능 |
| PC/320px 모바일, 화면 5개 언어 | 격리 화면 검증 완료 |
| 실제 운영 배포 | Pages/Render 성공, 게시 파일/서버 버전 일치 확인 |
| 실제 운영 소유 작가의 본문 조회 | 괴물의 현재 본문/선택지 3개 조회와 반복 조회 확인 |
| 실제 AI 문체/인물/시간선 품질 및 엔딩 | 이번 기능으로 검증하지 않음 |

## 2. 동작

`GET /api/v1/me/creator-studio/stories/:workId/body-preview?locale=ko`는
로그인한 소유 작가 본인의 기존 진행만 읽는다. 진행이 없으면 빈 상태를 반환하고
자동으로 시작하지 않는다. 원작과 생성 장면 모두 요청한 언어의 저장된 문장을 읽으며,
누락된 언어를 다른 언어로 대체하거나 새로 번역하지 않는다.

- 서버 집중 검사 62개 통과: 정상 5개 언어, 다른 소유자/작품/경로 차단,
  오래된 공개 기준, 누락 언어, 잘못된 UUID/입력, 중복 행, 비정상 본문,
  최대 개수/크기, 종료/대기 상태, 미로그인, 오류 응답의 캐시 차단.
- 기존 분기/공유/그림 HTTP 회귀 검사 80개 통과. 이번 62개와 중복 합산하지 않는다.
- 화면 집중 검사 202개와 공개 파일 경계 검사 27개, 합계 229개 통과.
- 배포 전 전체 정적 화면 검사 2,177개 통과, 4개 건너뜀, 실패 0개.
  위 집중 검사도 포함한 전체 실행이므로 별도 성과로 더해 계산하지 않는다.
- 공개 산출물 550개 파일의 목록/해시 검증 통과. 시험 기록과 서버 소스는
  공개 산출물에 포함되지 않는다.
- 운영 소스 및 추가 시험의 타입 검사 통과.
- 실제 PostgreSQL 격리 시험 5개 통과, 기존 DB 이관 99개 적용.
  반복 조회 전후 진행/장면/선택/공유 검수/사용량/공동 기억/그림 작업/지갑 등
  기록이 동일함을 확인했다. 실제 DB의 읽기 전용 트랜잭션에서 수정도 거부됐다.
- 실제 브라우저의 격리 화면에서 PC 18px, 모바일 17px 본문과 5개 언어를 확인했다.
  가로 넘침 없음, 작품 전환/로그아웃 후 이전 본문 제거, 조회 10회와 쓰기 0회를 확인했다.

격리 PostgreSQL 시험은 실제 DB에 시험용 본문을 저장해 조회한 결과이며,
실제 AI 제공자 생성 시험이 아니다. AI 호출과 이미지 생성은 0회였다.
첫 준비 시도의 DB 시작 대기 실패와 다음 시험 환경의 지역 설정 누락은 기록을 보존하고
격리 준비를 수정한 뒤 새 DB에서 5개를 모두 통과했다. 제품 안전 조건을 우회하지 않았다.
본인이 시작한 시험 서버와 PostgreSQL은 종료했다. 시험 DB와 원본은 삭제하지 않았다.

동시 제공 경로는 변경하지 않는다. 공유 분기를 공개 승인하거나 다른 독자의 진행을

응답은 로그인 실패와 오류를 포함해 `private, no-store`로 반환한다.

## 4. 이해

독자에게 보여줄 완성 장면과 작가가 확인하는 검토용 본문을 분리했다.
그림이 준비되지 않은 장면을 독자에게 완성품처럼 공개하지 않으면서도,
작가는 이미 저장된 자신의 문장을 확인할 수 있다.

조회할 때도 원고의 공개 버전과 자신의 경로가 맞는지 확인한다. 화면에서 작품이나
언어를 바꾸면 늦게 도착한 이전 응답을 버리고, 로그아웃하면 본문을 지운다.
DB 자체를 읽기 전용으로 묶어 확인 버튼이 생성 비용이나 진행 변경으로 이어지지
않도록 했다. 본문 조회 성공은 작가의 내용 승인이나 AI 품질 합격과 다르다.
